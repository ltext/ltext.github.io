yay -S ltext-bin

Downloads

  • Debian, Ubuntu: .deb x86_64 · arm64
  • Fedora, RHEL, openSUSE: .rpm x86_64 · aarch64
  • Any distribution (static binary): x86_64 · aarch64

macOS

Package managers

Homebrew
brew install ltext/tap/ltext

Downloads

  • Apple silicon
  • Intel

macOS may quarantine a downloaded binary; xattr -d com.apple.quarantine ltext clears that.

Windows

Downloads

  • x64: ltext.exe · .zip
  • ARM64: ltext.exe · .zip

A single standalone executable: rename it to ltext.exe and put it somewhere on your PATH.

or, on any platform

Cargo

From crates.io:

cargo install ltext

or, with cargo-binstall, the prebuilt binary:

cargo binstall ltext

Nix

Run it straight from the flake:

nix run github:ltext/ltext -- --help

or install it into your profile:

nix profile add github:ltext/ltext

Container

A ~1 MB image (amd64, arm64) that renders files in the current directory:

docker run --rm -v "$PWD:/work" ghcr.io/ltext/ltext "foo bar"

or copy it into your own image:

COPY --from=ghcr.io/ltext/ltext /usr/local/bin/ltext /usr/local/bin/

Build From Source

λtext needs Rust 1.85 or newer. 

git clone https://github.com/ltext/ltext
cd ltext
cargo install --path .
